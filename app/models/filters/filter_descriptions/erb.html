Lets you use Embedded Ruby within a page. For example:

<r:erb>Time is <% Time.now %></r:erb>

produces something like:

Time is Tue Mar 08 09:34:26 +0000 2011

The return values of Rails calls request and session are made available as instance variables @request and @session.

If producing output that can vary per-request, you will need to use a page type that bypasses the cache (such as "News").

For more, please see ruby-doc.org.
