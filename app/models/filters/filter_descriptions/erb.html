Lets you use Embedded Ruby within a page. For example:

<r:erb>Time is <% Time.now %></r:erb>

produces something like:

Time is Tue Mar 08 09:34:26 +0000 2011

The template is interpreted within the rendering site controller's binding context, so familiar objects such as request or session will be available, along with the helpers accessor to get at helper methods. Do not invoke render, or you will provoke a Double Render Error internally and the rendered output will be heavily broken.

If producing output that can vary per-request, you will need to use a page type that bypasses the cache (such as "News").

For more, please see ruby-doc.org.
